# Сайт для экспорта авто из Японии

Три варианта дизайна на одной кодовой базе:

- `kuro/` — тёмный, для люкса
- `hikari/` — светлый, минималистичный
- `sora/` — маркетплейс с фильтрами и ценами в $, ₸ и ¥

Статика, без сборки. Данные по машинам лежат в `data/cars.js`, общая логика (фильтры, галерея, формы, оценка цены) в `shared/core.js`.

Локально: `python3 -m http.server` в корне и открыть http://localhost:8000/sora/
